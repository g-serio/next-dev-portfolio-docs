**next-dev-portfolio** is a production-ready Next.js portfolio template powered by OlonJS. Deploy it to Vercel with a single click and get a fully functional site — with a blog, case studies, contact page, and a built-in visual editor — all backed by type-safe JSON content that lives in your own repository.

## What you get

When you deploy next-dev-portfolio, you get a complete portfolio site with everything wired up:

- **Public portfolio pages** — Home, About, Work (case studies), Blog, and Contact, each built from validated JSON data
- **Built-in Studio** at `/admin` — a visual CMS for editing any section of your site without touching code
- **Save2Repo** — edits made in Studio are committed directly back to your GitHub repo via the Vercel integration
- **Schema contracts** — every page section is validated by a Zod schema so content never silently breaks
- **SEO out of the box** — JSON-LD structured data, sitemap.xml, robots.txt, and Open Graph meta generated automatically
- **AI discoverability** — MCP manifests on every page make your content readable by AI agents and assistants

## How to get started

<Steps>
  <Step title="Deploy to Vercel">
    Click the Deploy button on the [Deploy to Vercel](/deploy-to-vercel) page. Vercel will clone the repo to your GitHub account and set up the Save2Repo integration automatically.
  </Step>
  <Step title="Open your site">
    Once the build completes, open your new site URL. You'll see the default portfolio content — Andrew Linh's placeholder data — ready to be replaced with your own.
  </Step>
  <Step title="Edit in Studio">
    Navigate to `/admin` on your deployed site. Click any section to edit it inline. Changes are saved to a JSON file and committed back to your repo.
  </Step>
  <Step title="Customize theme and content">
    Update `src/data/config/site.json` for global branding and `src/data/config/theme.json` for colors and typography. Redeploy to apply the changes.
  </Step>
</Steps>

<Note>
  The Save2Repo integration requires your deployment to be connected to GitHub. If you deploy manually without the Vercel integration, Studio saves are written to the local filesystem only.
</Note>
