## New features

- **One-click Vercel deploy.** Launch a live portfolio in under five minutes. The Save2Repo Vercel integration is installed automatically, so there is no manual configuration. See the [quickstart](/quickstart).
- **Studio CMS at `/admin`.** Edit any page, section, blog post, or project visually on your deployed site. Every save commits straight back to your GitHub repo. See the [Studio overview](/studio/overview).
- **Schema-validated content.** Zod schemas validate every piece of content at build time so mismatched fields fail the build instead of silently drifting. See [schema validation](/advanced/schema-validation).
- **Blog with Markdown and MDX.** Write posts with tags, publication dates, cover images, and automatic reading-time estimates. See [blog posts](/content/blog-posts).
- **Case study portfolio.** Showcase projects with role, timeline, tech stack, and embedded media. See [projects](/content/projects).
- **MCP manifests and `llms.txt`.** Auto-generated manifests make your portfolio discoverable by AI agents and LLM tooling. See [MCP manifests](/advanced/mcp-manifests).

## Updates

- **Theme, navigation, and section customization.** Tune colors, layout, and which sections render on each page from JSON. See [theme](/customization/theme), [navigation](/customization/navigation), and [sections](/customization/sections).
- **Asset management in Studio.** Upload and reuse images directly from the visual editor. See [assets](/studio/assets).
- **Environment variables reference.** All supported variables are now documented in one place. See [environment variables](/advanced/environment-variables).
